# Bartley-SC-App
Development app for running sailing races.

Hub-and-spoke platform for club race management on the web and a personalised sailor experience on mobile.

## Current status

The product is now broadly aligned with the **Phase 1 MVP**, with the remaining work focused on sign-off, race-day validation, and release readiness.

## Minimum viable product — Phase 1

### Web app
- add members and link mobile users
- add new race series and generate upcoming races
- review and amend races that have taken place
- manually add race data
- collect race data, timings, and entries as it happens
- view series results

### Mobile app
- add sailor profile and assign user to club
- enter upcoming races
- view latest races and results
- collect race data, timings, and entries as it happens for eligible race-control users
- receive Phase 1 notifications
- work offline with cached data and queued actions

## Phase 2

### Web app
- event support
- QR sign on
- duty manager
- messaging
- personal handicapping
- race status (abandoned/postponed)
- local handicap recommendations

### Mobile app
- sailor stats
- event entry
- entry confirmation alerts

## Phase 3

### Web app
- expanded event support and communications

### Mobile app
- community stats
- social features
- start countdown alerts (5 min + 1 min)

## Phase 4

### Web app
- automated timing with RFID

### Mobile app
- future enhancements to be defined

## Notifications roadmap

- results published — Phase 1
- personal result summary — Phase 1
- upcoming race reminder — Phase 1
- race postponed / abandoned — Phase 2
- entry confirmation — Phase 2
- start countdown (5 min + 1 min) — Phase 3

## Core user journeys

**Web**
Setup series -> Start race -> Record race results

**App**
Enter race -> Receive results -> View series results
